# .gitignore - Documentação

## Descrição da Mudança
Criação do .gitignore para ignorar arquivos gerados, dependências e arquivos sensíveis.

## Arquivo
- `.gitignore` (raiz do repositório)

## Padrões Incluídos
- `node_modules/` - Dependências (backend e frontend)
- `dist/`, `build/` - Builds de produção
- `.env*` - Variáveis de ambiente
- `*.log` - Logs
- `.vscode/`, `.idea/` - Configurações de IDE
- `.DS_Store`, `Thumbs.db` - Arquivos de SO
- Específicos backend/frontend
